## Entry

## How it works

`main.ts` (Node 22 stdlib only) writes the one-line excuse to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`). A `validate()` guard throws if the line
breaks the gate: it must be 1–180 characters, a single line, and not only
whitespace.
